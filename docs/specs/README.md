# Module Specifications

Each file corresponds to one stable module id in the accepted capability map. All
modules inherit the commands, style, test strategy, and boundaries in
`../PROJECT_SPEC.md`.

Status meanings:

- `READY FOR REVIEW`: contract is written; implementation has not started.
- `APPROVED`: the module may enter its tasks in dependency order.
- `IMPLEMENTED`: acceptance evidence is linked and the module gate passed.
